## 2024-10-31 - Stored/Reflected XSS via SVG Rendering
**Vulnerability:** Found multiple instances where SVG content (`output.svg`, `svgOutput`) was being directly rendered using React's `dangerouslySetInnerHTML` without proper sanitization in `DeedPlanGenerator.tsx` and `MutationPlanGenerator.tsx`.
**Learning:** `dangerouslySetInnerHTML` will happily render harmful `<script>` tags, event handlers (`onload`, `onclick`), and other dangerous attributes embedded inside SVGs if they are not strictly controlled. Given that SVG generation might include user-controlled inputs (like parcel names, descriptions, and surveyor names), this poses a high risk for XSS attacks.
**Prevention:** Always use a configured `DOMPurify` (or similar sanitizer) via `sanitizeHtml` before passing any dynamically generated or user-controlled SVG/HTML into `dangerouslySetInnerHTML`. Ensure the sanitizer whitelist correctly allows required SVG tags while stripping harmful tags (`script`, `foreignObject`, etc.) and malicious event handlers.
