## 2024-05-24 - [Fix Stored XSS via unsanitized SVGs rendered with dangerouslySetInnerHTML]
 **Vulnerability:** Unsanitized survey plan SVG data was rendered using `dangerouslySetInnerHTML` in `src/components/deedplan/DeedPlanGenerator.tsx` and `src/components/mutationplan/MutationPlanGenerator.tsx`. Although the codebase had `escapeXml` functions for individual inputs during SVG generation, failure to consistently sanitize the final raw SVG document before React hydration exposes the app to Cross-Site Scripting (XSS) if any upstream data bypasses standard escaping.
 **Learning:** In complex SVG-generating workflows, interpolating raw, un-sanitized output directly into `dangerouslySetInnerHTML` is a severe risk. Even if helper functions exist (like `escapeXml`), defense in depth dictates that the final output payload must always pass through a robust HTML sanitization library (like `DOMPurify` via `@/lib/security/sanitizeHtml`) prior to render.
 **Prevention:** Always wrap dynamically generated SVGs, HTML strings, or API-delivered markup in `sanitizeHtml()` before supplying them to `dangerouslySetInnerHTML`. Relying solely on localized character escaping deep within data processors is fragile and error-prone.
