## 2026-10-27 - Fix XSS in SVG Rendering
**Vulnerability:** The Deed Plan and Mutation Plan generators were rendering un-sanitized SVGs containing user data directly into the DOM using `dangerouslySetInnerHTML` and `document.write`.
**Learning:** Even though SVG generated server-side or via generators is expected to be safe, user input (like project names or strings) could potentially introduce script tags or other XSS vectors if escaped improperly.
**Prevention:** Always use the carefully configured `sanitizeHtml` function from `@/lib/security/sanitize` when rendering SVGs or HTML dynamically, even if it is generated by our own code, to enforce a secure whitelist of tags and attributes.
