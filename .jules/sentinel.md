
## 2026-11-08 - [HIGH] Fix XSS vulnerabilities in SVG rendering
 **Vulnerability:** Unsanitized dynamically generated SVG strings (containing potentially unsafe, user-supplied data such as parcel numbers or project names) were being rendered directly using `dangerouslySetInnerHTML` in React components (`DeedPlanGenerator.tsx` and `MutationPlanGenerator.tsx`). This exposes the application to stored XSS if a malicious surveyor enters `<script>...</script>` payloads in string fields which then get interpolated into the final SVG.
 **Learning:** In complex mapping and surveying applications where large chunks of SVG XML are constructed as strings containing user inputs, simply assuming the `<svg>` is safe is incorrect. React's `dangerouslySetInnerHTML` will happily execute any `<script>` or event handler embedded within that raw HTML string.
 **Prevention:** Always wrap dynamically generated SVG (or any untrusted HTML string) with a robust sanitization library like DOMPurify (which is wrapped by the project's `sanitizeHtml` utility) before passing it to `dangerouslySetInnerHTML`. Specifically, the project already provides `sanitizeHtml` in `@/lib/security/sanitize` precisely for this purpose.
