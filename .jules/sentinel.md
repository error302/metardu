## 2025-02-27 - [Stored/Reflected XSS in SVG Generation]
**Vulnerability:** The codebase uses `dangerouslySetInnerHTML` to render generated SVG previews in `DeedPlanGenerator` and `MutationPlanGenerator` directly from the generated SVG strings. These SVGs compile user inputs. While `escapeXml` is used in some places in the renderers, if any field bypasses escaping or if malicious tags like `<script>` or `<image href="javascript:...">` are directly injected, they would be executed by the browser because `dangerouslySetInnerHTML` accepts the payload blindly.
**Learning:** `dangerouslySetInnerHTML` without proper sanitization at the point of rendering represents an XSS risk. Although there is a `sanitizeHtml` wrapper configured with DOMPurify available in `@/lib/security/sanitize`, it was missing in `DeedPlanGenerator` and `MutationPlanGenerator`.
**Prevention:** Always wrap dynamically generated SVG or HTML content with the `sanitizeHtml` wrapper from `@/lib/security/sanitize` before passing it to `dangerouslySetInnerHTML`.
