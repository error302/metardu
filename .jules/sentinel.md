## 2023-10-27 - Stored XSS in dynamically generated SVGs rendered with dangerouslySetInnerHTML
**Vulnerability:** Components like `DeedPlanGenerator` and `MutationPlanGenerator` were rendering dynamically generated SVG strings directly into the DOM using `dangerouslySetInnerHTML` without proper sanitization, leading to potential Cross-Site Scripting (XSS).
**Learning:** Even generated SVG outputs (like those from custom APIs or algorithms) must be sanitized before rendering because they might embed or reflect unescaped user inputs or malicious payloads. Manually specifying `ALLOWED_TAGS` and `ALLOWED_ATTR` in DOMPurify is prone to missing necessary tags or attributes required for functional SVG rendering (e.g., `cx`, `cy`, `points`).
**Prevention:** Always use the provided `sanitizeHtml` wrapper from `@/lib/security/sanitize` when rendering untrusted or dynamically generated HTML/SVG via `dangerouslySetInnerHTML`. Furthermore, configure DOMPurify with `USE_PROFILES: { html: true, svg: true }` instead of manual lists to guarantee security while avoiding functional regressions with SVGs.
