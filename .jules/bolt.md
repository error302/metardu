## 2026-08-20 - Optimize Math.min/max for Large Arrays\n**Learning:** Avoid using the spread operator (`...`) with `Math.min()` or `Math.max()` on large arrays (like spot heights or point clouds). This causes V8 'Maximum call stack size exceeded' errors and allocates multiple intermediate arrays when used with `.map`.\n**Action:** Always use a single-pass `for` loop or `.reduce()` to calculate bounds on large data sets to improve performance and prevent stack overflow errors.
