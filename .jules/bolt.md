## 2024-03-24 - Avoid Math.min/Math.max with Spread on Large Arrays
**Learning:** Using `Math.min(...array)` or `Math.max(...array)` on large datasets (like point clouds or spot heights) causes V8 "Maximum call stack size exceeded" errors. It also incurs significant memory allocation overhead if mapped directly beforehand.
**Action:** Replace spread operators on large arrays with standard `for` loops or `reduce` calls to compute bounding boxes and min/max values efficiently without hitting stack limits.## 2024-11-04 - Next.js Build Out of Memory\n**Learning:** Next.js `npm run build` will exhaust Node.js heap memory, resulting in 'Ineffective mark-compacts near heap limit Allocation failed - JavaScript heap out of memory', if run without a sufficient `NODE_OPTIONS='--max-old-space-size=...'` parameter.\n**Action:** Use `NODE_OPTIONS='--max-old-space-size=6144'` (or higher) to provide Next.js with enough heap space to complete compilation of the app successfully.
