# Native report font

Unmodified JetBrains Mono Regular, publisher release v2.304:
https://raw.githubusercontent.com/JetBrains/JetBrainsMono/v2.304/fonts/ttf/JetBrainsMono-Regular.ttf

Copyright 2020 The JetBrains Mono Project Authors. The existing
`JetBrainsMono-OFL.txt` contains the publisher's SIL Open Font License 1.1.
The static TTF is used by the PDF engine; existing web-font assets remain intact.

SHA-256: `a0bf60ef0f83c5ed4d7a75d45838548b1f6873372dfac88f71804491898d138f`.
`JetBrainsMono-coverage.json` records the original character map and binds it to
that digest. PDF text outside this coverage is rejected with an HTML/CSV fallback
instead of silently losing characters.
